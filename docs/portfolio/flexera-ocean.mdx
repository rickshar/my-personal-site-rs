# Ocean Product Documentation at Flexera

I worked at Flexera (previously known as Spot by NetApp) from Feb 2024-April 2026.
In addition to team-leading duties, I documented and maintained the [Ocean](https://docs.flexera.com/spot/ocean/) (Kubernetes-based product) from a GitHub repository, implemented as a static HTML site, initially through [Docsify](https://docsify.js.org/#/), and later migrated by myself and colleagues to the current implementation in [Docusaurus](https://docusaurus.io/).
